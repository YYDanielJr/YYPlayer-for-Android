# 视频体验 U15–U16（2026-10-14）

## 2026-10-14 U19：自由倍速与 dev 提交

「播放工具 → 播放倍速」提供 0.1×–10× 自由调节：滑杆按 0.1× 吸附、松手生效，两个按钮每次加减 0.1×，并可恢复 1×。外侧倍速菜单仍为 0.5／1／1.25／1.5／2／3，1.25× 不被全局舍入。边界按钮禁用，无障碍 SetProgress 也立即应用。

Media3 1.11.1 当前 AudioSink 软件变速实际最高 8×；超过 8× 使用已有 libmpv，调节页提前说明，保留位置／播放意图／音量。仅硬解模式最高 8×，需用户先修改解码策略才可更高；不静默软解。降速不自动切回，手动选择 Media3 时速度限制到 8×。长按仍是绝对 3×，松手恢复原速。见 [ADR0008](adr/0008-video-speed-range.md)。

本轮用户授权将累计 U15–U19 与文档提交 dev，旧章节“未提交”属于历史状态；验证与限制见 [U19](validation/video-u19/README.md)。


## 2026-10-14 U18：抽屉触摸修复与子菜单返回

修复 U17 父级过度消费事件导致真实拖动失效的问题，正常打开时由列表处理上下滑动，退出动画期间继续阻止误触。子菜单标题左侧新增“返回上一级”箭头，系统返回键逐级退回；字幕 → 同步可回到字幕，再回工具。底栏快捷进入的设置也可返回工具。完成／取消和点击左侧空白关闭整个抽屉。

U17 的程序化滚动未覆盖真实触摸，本轮加入 swipeUp／swipeDown 位移断言与多级返回实播测试；8 项通过。见 [U18 验证](validation/video-u18/README.md)。


## 2026-10-14 U17：横屏右侧半透明设置抽屉

横屏时，播放工具、字幕／音轨、画面、倍速、队列、章节、同步、A–B 和媒体信息在同一个右侧抽屉中呈现；竖向布局保持 Miuix 弹窗。判断使用实际布局宽高，适配窗口缩放。抽屉宽 320–420dp，左侧 24dp 圆角，背景 90% 不透明，260ms 从右侧滑入／滑出；减少动态效果时直接切换。

标题和完成／取消固定，设置列表独立滚动并保留系统安全边距。打开设置时隐藏视频控制按钮、阻止底层无障碍访问；退出动画保留绘制但立即阻止内容误触。返回键、点击左側空白或完成关闭，视频 Surface 尺寸不变。MuMu 7 项专项通过及截图见 [U17 验证](validation/video-u17/README.md)；实体设备手感和完整无障碍仍待验。


## U16：可选 libmpv 与桌面视频功能

入口：视频页右上角「播放工具 → 视频后端 → libmpv · 扩展功能」。选择会保存，默认仍是 Media3；切换保留位置、基础速度、暂停意图和播放器音量。音乐继续使用既有 Media3／native PCM 输出。底层来源、线程和供应链决定见 [ADR0007](adr/0007-libmpv-video-adapter.md)，测试与截图见 [U16 验证](validation/video-u16/README.md)。

| 上轮缺项 | U16 实现 |
| --- | --- |
| 双向逐帧 | 直接使用 mpv frame-step／frame-back-step；暂停后操作，并等待实际 seeking 结束，不估算帧率 |
| 章节 | 读取真实 chapter-list，显示章节标题／时间并跳转 |
| 音频／字幕偏移 | 各自支持 ±10 秒、100ms 步进、单独还原；状态来自实际 mpv 属性 |
| 字幕样式 | libass 绘制 ASS／SSA 样式、定位、旋转／动画；默认保留文件样式，也可强制应用字号与无衬线／衬线／等宽预设 |
| 色阶 | gpu deband 开关，状态来自原生属性 |
| 带字幕截图 | libass 已绘入视频，单次 TextureView 截图包含字幕，不包含 Compose 控件 |
| 原视频能力 | 内／外字幕与音轨、A–B、视频顺序／循环／随机、绝对 3×、双指连续旋转／缩放仍可用 |

libmpv 复用已有窗口和手势；用真正的 SimpleBasePlayer 适配器接入 MediaSession。Surface 分离时在工作线程销毁旧 VO 后才释放 lease，重建保留当前视频的轨道选择、偏移、样式、位置与速度。音视频互切先收到旧输出销毁完成再启动新输出；音频自检也等待这个完成回调。普通命令有界，seek／状态轮询合并，generation 拒绝旧结果。

字幕导入保留 4 MB 上限。SRT／VTT 继续用锁定解析器预校验；Media3 路径继续限制 20000 条 cue。libmpv 的 ASS／SSA 由 libass 校验，兼容 Media3 没有文本 cue 的纯绘图字幕；原生加载成功 ACK 后才更新外置字幕名称。字幕只保留本次会话。系统字体可用三种家族预设，尚未提供 SAF 自选 TTF／OTF 或完整桌面系统字体清单。

仍未宣称全量桌面对等：桌面窗口／快捷键、音乐 DSP 与输出策略不在视频迁移中；全部高级渲染参数／shader、HDR、严格硬解资格、自定义字体导入和低版本兼容仍待后续。libmpv 当前跟随系统媒体输出；精确逐帧仍受源文件可寻址性与 mpv 本身对异常时间戳／变帧率的限制。当前样片验证不能代表所有容器和字幕特效已穷尽。

## 以下为 U15 基线记录


本轮由用户要求启动：优化小米风格的视频前端、解决双指放大的边界、添加还原与 3× 系统触感，并对照 Rust 桌面版补视频功能。所有修改在 dev，保留 U11–U14 音乐基线、唯一 runtime 播放器和系统 Activity 栈。验收结果见 [U15 验证](validation/video-u15/README.md)。

## 页面与手势

- 黑色沉浸画布、白色文字、轻渐变控制层。顶部仅返回、标题和工具入口；底部细进度条、播放、前后 10 秒、方向，以及速度、字幕／音轨、画面、队列、锁定。工具与选项使用现有 Miuix WindowDialog／WindowSpinnerPreference。
- 播放时控制层 3.5 秒自动隐藏；拖动进度、弹窗、暂停和错误期间保持可操作。锁定后只保留解锁和系统返回解锁。按钮至少 48dp，辅助操作允许换行。
- TextureView 的实际布局占满 viewport，比例适应在呈现变换中计算。放大可越过原始左右／上下黑边；裁切只发生在整个播放窗口。保留 0.5–5×、任意角旋转、双指重心锚点与归一化平移。缩放／旋转／平移或比例变化后，小型「还原」独立于自动隐藏的控制层。
- 比例选项：适应画面、保持比例裁切铺满、强制 16:9、强制 4:3。还原恢复适应、1×、0° 和居中。铺满屏幕可能裁掉画面边缘，强制比例会改变画面形状。
- 进入临时 3× 后调用一次系统 KEYBOARD_TAP 触感，遵循系统触感开关。后台、失焦、第二指、媒体切换、解码重建、结束与取消恢复基础速度；后端 token 防止旧松手覆盖新媒体或新速度。模拟器不能验证实体马达手感。
- 视频播放时保持亮屏，系统栏可从屏幕边缘临时唤出。仅改变播放器窗口，不改变全局系统设置。

## 字幕与播放功能

- 从真实 Media3 Tracks 显示可解码的字幕与音轨，支持关闭；选择携带媒体 generation，拒绝旧媒体选择。解码重建保留轨道参数、位置、速度、暂停意图。
- 用户通过 SAF 选择 SRT、WebVTT、ASS／SSA。按实际授权 flags 处理权限，后台限量复制到应用缓存（4 MB／20000 条上限），用锁定的 Media3 字幕解析器预校验；无有效 cue 时保留原播放。回到页面时验证 URI 与 generation，再重建当前视频。
- 外置字幕仅保持当前会话，支持移除；字体 16／20／24／30sp。字幕由 Media3 解码、SubtitleView 渲染，与视频缩放／旋转／平移共同变换。ASS／SSA 只提供 Media3 支持的基础文本与部分定位，不宣称 libass 完整特效。
- A–B 由后端 PlayerMessage 按实际播放位置触发 seek，至少间隔 500ms；UI 无计时跳转或第二套 EOF 推进。换媒体、清除或用户跳出区间撤销。它是普通片段循环，不保证采样精确或无缝。
- 视频支持顺序／单项循环／随机，独立于音乐模式。队列选择调用 jumpTo，不重建整条队列。
- 截图按用户点击单次读取当前 TextureView（最长边 1920），通过系统保存选择器写 PNG；不含字幕／控制层。无持续帧读取、无新增广泛存储权限。

## 与桌面版对照

只读核对 `crates/yyplayer-app/src/controller.rs` 的 audio-track、subtitle-track、chapter、subtitle-file、subtitle-delay、audio-delay、frame、screenshot、aspect、ab-loop 分支，以及 `crates/player-core/src/types.rs` 的真实命令。未修改 Rust 工程。

| 桌面能力 | 本轮安卓对应／差异 |
| --- | --- |
| 播放／暂停、进度、速度、临时 3×、全屏 | 原能力保留，增加触感、失焦／generation 防护和沉浸窗口 |
| 音轨、内嵌／外置字幕与关闭 | 已接入 Media3 实际轨道与 SAF 导入 |
| 字幕字体 | 新增字号；自选字体家族、ASS 强制字体覆盖未迁入 |
| 单项循环、随机、A–B | 已接入真实 timeline 与 PlayerMessage |
| 画面比例、截图 | 新增适应／铺满／16:9／4:3；单次截图不含字幕，和桌面带字幕截图不同 |
| 逐帧前进／后退 | 尚未实现；不能用 FPS 推算的 seek 冒充精确逐帧，需后续 native 解码能力 |
| 音频／字幕时间偏移 | 尚未实现；当前 Media3 适配器未提供等价且经过同步验证的后端契约 |
| 章节 | 尚未实现通用容器章节枚举／跳转；不能把普通时间段当真实章节 |
| libass 高级特效、deband、桌面渲染选项 | 尚未迁入；依赖后续 libmpv／FFmpeg／libass 供应链和呈现 gate |
| EQ、输出策略、快捷键、窗口装饰和桌面背景 | 属于音频／桌面平台能力，不在本轮视频页中移植；HiFi 状态仍以 ADR0006 为准 |

因此本轮是视频体验和可用功能补齐，**不是 Rust 全功能对等或 native 后端替换**。

接口依据：[Media3 轨道选择](https://developer.android.com/media/media3/exoplayer/track-selection)、[PlayerMessage](https://developer.android.com/reference/androidx/media3/exoplayer/PlayerMessage)。新增字幕解析接口另以本地锁定 media3-extractor 1.11.1 的 class 签名核实，未升级依赖。
