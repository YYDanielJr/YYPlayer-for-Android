# ADR 0005：可配置在线音乐与歌词

日期：2026-10-05。用户授权在 `dev-api` 实现联网音乐与歌词；长期 native 架构不变。

决定：采用 version=1 JSON 声明式 provider。请求、响应字段、来源和音质分离；不执行 JS/LX 脚本。音乐和歌词联网开关独立、默认关闭，运行时和界面双重检查。独立在线搜索使用原生 Activity；音乐详情继续 MainActivity 内 U05 覆盖层。

使用平台 HTTPS 客户端执行后台有界请求，Media3 同一引擎串流。API headers 与媒体 headers 分开，重定向不传鉴权至其他主机。返回码率只是服务报告，不当输出音质资格。下载采用 SAF 用户授权目录，临时文件、取消清理、完成后入库；歌词保存为关联文件，关闭联网仍可读本地缓存。

配置通过 SAF 导入验证后原子替换，保留上次有效配置；私有 headers 不进日志或备份。GD 示例需按服务现状验证；服务失败显示错误，不绕过挑战或伪造结果。

接口规格、限制和验证见 [ONLINE_API](../ONLINE_API.md)；实际验收以 [STATUS](../STATUS.md) 为准。

2026-10-05 下载体验补充：默认使用 API29+ MediaStore 的 Music/ 音频集合，以 IS_PENDING 隔离未完成文件；用户选择的自定义目录继续用 SAF，API26–28 首次下载先授权 Music 或其他目录。无全盘存储权限。自有 MediaStore URI 与来源标志持久化，重开应用不依赖 SAF 授权；歌曲格式由有界文件头识别，未知格式拒绝保存，不信任 MIME、URL 后缀或文件大小。确定扩展名后按“歌名 - 歌手”命名，碰撞才加数字序号。专辑图通过可选 artwork 操作获取，校验／缩采样后持久保存于应用内；SAF 另写同名 JPG 与 LRC，MediaStore 的非媒体歌词保持应用内关联。音质列表由配置、曲目可用列表、来源限制和实际 URL 接口报告共同决定，服务返回其他已配置档位时拒绝以原档位下载；这不等同于完整音频解码或设备输出资格。
